## Overview

This repository documents the **analog front-end (AFE) hardware platform** designed and fabricated for low-cost Electrooculography (EOG) signal acquisition. The platform was developed as part of our undergraduate research at the Department of Biomedical Engineering, University of Science and Technology, Aden, Yemen.

The AFE captures the microvolt-level corneoretinal potential changes generated by eye movements, amplifies and filters them into clean, digitizable signals suitable for real-time processing. This platform served as the foundational hardware for our senior capstone graduation project: [eog-assistive-hci-keyboard](https://github.com/Abdulaziz-kh-Hatem/eog-assistive-hci-keyboard), an integrated EOG-based virtual keyboard and wheelchair navigation system.

## System Architecture

The signal conditioning chain consists of five cascaded analog stages:

```
[ Ag/AgCl Electrodes on Face ]
            │
            ▼
[ 1. Instrumentation Amplifier (AD620) ] ──> Gain: 6x, CMRR: >100 dB
            │
            ▼
[ 2. Active High-Pass Filter (TL072) ]   ──> Sallen-Key, fc = 0.8 Hz (removes DC drift)
            │
            ▼
[ 3. Active Low-Pass Filter (TL072) ]    ──> Sallen-Key, fc = 30 Hz (removes muscle noise)
            │
            ▼
[ 4. Twin-T Notch Filter (50 Hz) ]       ──> Eliminates power-line interference
            │
            ▼
[ 5. Variable Gain Stage (TL072) ]       ──> Final amplification up to 100x total
            │
            ▼
[ DC Level Shift (+2.5V) ]               ──> Maps signal to Arduino ADC range (0–5V)
            │
            ▼
[ ATmega328P (Arduino) ADC @ 10-bit ]    ──> USB Serial to laptop for MATLAB processing
```

## Key Specifications

| Parameter | Value |
| :--- | :--- |
| **Input Signal Range** | 50–3500 µV (corneoretinal potential) |
| **Pre-Amplifier** | AD620, Gain = 6x |
| **High-Pass Cutoff** | 0.8 Hz (Sallen-Key, 2nd order) |
| **Low-Pass Cutoff** | 30 Hz (Sallen-Key, 2nd order) |
| **Notch Filter** | Twin-T, 50 Hz (power-line rejection) |
| **Total System Gain** | Up to 100x |
| **Power Supply** | Dual-rail ±9V (2× 18650 Li-ion cells with BMS) |
| **ADC Interface** | ATmega328P, 10-bit, USB Serial to MATLAB |
| **Estimated Component Cost** | < $15 USD |
